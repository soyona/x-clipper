## Decision rules

- High impressions but low GitHub visits: revise the opening hook or CTA.
- High GitHub visits but low Stars: revise README positioning, proof, or trust signals.
- Stars but few downloads: reduce manual-install friction or clarify who should install now.
- Downloads with repeated install blockers: fix packaging and instructions before increasing exposure.
- High saves or substantive comments on 小红书 but weak GitHub traffic: improve the path from profile/content to the repository without claiming the extension provides access to X.
- Qualified feedback repeating the same need three or more times: consider it for the product backlog; do not promise it immediately.
